# Primary User

The main user is a hackathon organizer.

The organizer should be able to:

1. Create campaign
2. Upload registration data
3. Configure selection
4. Run evaluation
5. View ranking
6. Inspect teams
7. Understand score breakdown
8. Review rejected teams
9. Override decisions
10. Export results
